Event overview

About the Event

SEU Tech Event 2026 is a student-focused technology event designed to bring together learners who are interested in modern web development, programming, problem solving, and collaborative project work.

The main goal is to help students learn from short technical sessions, practical demonstrations, and peer interaction while building confidence in using web technologies.

Participation: Students may attend the sessions, join practical activities, and register for a preferred event date using the form below.

Visit the Southeast University website for university information.

What students will experience

Event Highlights and Participation Plan

Event Highlights

  • Introductory sessions on HTML, CSS, and JavaScript
  • Hands-on webpage building activities
  • Team-based problem solving and idea sharing
  • Short presentation and feedback session

How to Participate

  1. Read the event information and schedule.
  2. Select a suitable date and participation type.
  3. Complete the registration form.
  4. Attend the selected event session.

Technical Tracks

  • Web Development Track
    1. HTML page structure
    2. CSS styling and responsive layout
    3. Basic JavaScript interaction
  • Student Project Track
    • Idea presentation
    • Team discussion
    • Project feedback

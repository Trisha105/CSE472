# CSE 472 - Lab 01 HTML Submission

## Assignment
**SEU Tech Event Information and Registration Page**

This folder contains the complete single-page HTML5 assignment prepared from the official CSE 472 HTML Lab Manual.

## Files
- `index.html` - semantic HTML page
- `style.css` - responsive presentation styles
- `images/tech-event-banner.svg` - local event image
- `report/lab01_report.tex` - complete LaTeX lab report

## How to run
Open `index.html` in a modern browser. No server or installation is required.

## Requirement checklist
- Proper HTML5 document structure
- `header`, `nav`, `main`, at least three `section` elements, and `footer`
- One main `h1` with suitable subheadings
- Meaningful event, goal, and participation paragraphs
- Meaningful `div` and `span`
- Working hyperlink
- Image with `alt` text
- Unordered, ordered, and nested lists
- Table with a header row and four data rows
- Registration form with full name, student ID, email, preferred date, radio group, checkbox options, and submit button
- Clean indentation and responsive CSS

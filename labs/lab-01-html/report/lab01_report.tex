\section{Short Theory}
HTML stands for HyperText Markup Language. It is used to describe the structure of content on a webpage. A browser reads HTML elements and renders headings, paragraphs, links, images, lists, tables, forms, and other page components.

A standard HTML5 document starts with \texttt{<!DOCTYPE html>} and contains \texttt{html}, \texttt{head}, and \texttt{body}. The \texttt{head} section stores metadata, the title, responsive viewport settings, and links to resources such as CSS. The \texttt{body} contains visible content.

Semantic tags such as \texttt{header}, \texttt{nav}, \texttt{main}, \texttt{section}, and \texttt{footer} make the page structure easier to understand. Lists organize related items, tables present data in rows and columns, and forms collect user input. Labels are connected to form controls through matching \texttt{for} and \texttt{id} attributes.

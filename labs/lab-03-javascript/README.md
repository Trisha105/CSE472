# Lab 03: Student Workshop Registration System

Open `index.html` in a modern browser. The page uses `css/style.css` and `js/script.js`; no framework or build step is required.

The four buttons call `checkRegistration()`, `checkSeats()`, `showGreeting()` and `showWorkshopReminder()`. They use exact HTML IDs and `textContent` for paragraph updates. The greeting reads the existing Full Name input, now named `studentName`. Final `availableSeats` is 12. The zero-seat branch was tested and the value restored.

The stylesheet is an unchanged copy of the existing Lab 02 stylesheet. The earlier HTML structure and form are retained. The original repository was missing its banner image; a labelled text panel occupies that figure area in this Lab 03 copy. `assets/images/README.md` retains the required images directory in Git. No older lab was modified.

This is a classroom demonstration. It does not reserve seats or send registration details to a backend. JavaScript form validation, arrays, objects and storage are not part of this lab.

The accompanying package includes the LaTeX report, evidence and test logs. Preparation tests used real Chromium preview execution and separately checked local paths because direct local navigation was blocked in the managed environment. The student must also open and test the delivered page locally before submission. No GitHub push was performed as part of creating this package.

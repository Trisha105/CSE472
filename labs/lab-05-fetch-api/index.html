Lab 05 overview

About the Project

This project keeps the Student Workshop Registration System from the earlier lab stages and adds browser-server communication with the Fetch API.

Workshop information is stored in a separate JSON file and appears only after the user clicks a button. A second button requests a sample user from JSONPlaceholder.

Request-Response Idea

GET: receives data from a resource.

200: means the request was successful.

404: means the requested resource was not found.

Project Stage 05

New Lab Features

  • Local JSON data requested with fetch().
  • async and await used for the response.
  • response.status === 200 checked before reading JSON.
  • Six JSON values displayed on the webpage.
  • One public API request using JSONPlaceholder.
